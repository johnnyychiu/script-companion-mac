Reset all slides to line 1?

Every slide in this reader will start at its first note line, including the slide you are reading now. This replaces your saved reading positions.

Your current slide, note text, snapshots and timers will stay unchanged. No PowerPoint slide command will be sent.

Notes first · version 0.5.3

The highlighted line starts just 4 pixels below the top of the reading area. The slide number and title are now below the notes, beside the snapshot and above the timer, in both normal and Compact mode. The normal Mac window title bar remains. Move the Mac reader window towards the top of your laptop display.

Elapsed timer: choose Start timer, Pause/Resume, or press T with this reader focused. Reset asks for confirmation and clears timing only. The large timer totals your running time across all slides; This slide adds up all visits to the current slide. Timers do not reset on slide changes or a PowerPoint disconnect. Restored timers open paused; up to five seconds may be lost after a crash.

Faster following: lightweight position checks are separate from the slower notes refresh. Notes are refreshed periodically, and missing/new slide notes are requested when needed. The script moves only after PowerPoint confirms a slide. Use Refresh notes after changing or rearranging the deck. Real Mac performance is not measured by the browser tests.

Reset reading positions: the lower ↺ Reset all slides to line 1 button asks for confirmation, then resets all saved slide positions, including the current one. It does not change slides, edit notes, remove snapshots or reset/pause your timers. Slides with no notes stay empty. The existing ↺ Line 1 button resets only the current slide.

Private notes. Clear next line.

Projector setup: use extended displays, never mirroring. Keep this reader on your Mac display and verify the projector before starting.

Import: save your presentation as .pptx with speaker notes, then use Import. Each notes paragraph / line becomes a speaking line. Notes-page images and formatting are not imported.

Arrow keys: ↓ next line; ↑ previous line. → next slide; ← previous slide. Home / End selects the first / last line. A line key never changes slides, even at the last line. In browser practice, slide keys change only this reader.

Slide preview: Preview → Load images accepts PNG / JPEG slides or a ZIP. Confirm the file-to-slide mapping before use. The saved image follows the selected slide, or PowerPoint while linked. Animations and new visual edits are not live. P shows / hides it. Importing a different script clears the old images.

Live Mac link: start the slideshow, then Link PowerPoint and confirm the presentation. Notes and slide count are read from PowerPoint. Enable PowerPoint keys, then click an unobscured part of Presenter View on your Mac. While PowerPoint has focus, the companion captures only ↑ / ↓ for script lines; ← / → reach PowerPoint unchanged, including animation steps. These PowerPoint-focused horizontal keys remain native and are separate from the reader’s slide buttons. The reader follows actual slide changes after its next status check; it never guesses a slide change after an animation. Clock, images and each slide’s remembered line remain in use.

Slide buttons — 0.4.2: after linking, choose Slide buttons: Set up and select the Presenter View or audience slideshow window, never the editing window. The native app focuses that chosen window and sends the target slide number followed by Return. It checks PowerPoint’s actual slide before changing the reader. Accessibility permission is required. Setup does not itself change a slide; click a slide button after setup. The old AppleScript slide-jump command is not used. Buttons jump absolute slides, skipping animations; custom slideshow order is unsupported. An unconfirmed request is not automatically resent. A blocked focus or text field produces an error instead of typing into it. Choose Set up again when the slideshow window changes. This native path still needs Mac rehearsal testing.

PowerPoint keys: On optionally captures the Up/Down keys while PowerPoint has focus and this reader is visible and linked. This requires Accessibility permission. Switch it off before editing PowerPoint. Escape switches it off and still reaches PowerPoint. Without this option, click the reader before using plain arrow keys. Live automation and full-screen placement still need testing on your Mac.

Global line keys: in the Mac menu, opt in to ⌘⌥↓ / ⌘⌥↑. They move only the script highlight while PowerPoint has focus. They are disabled while editing. Standard clickers may send Page Up / Down rather than arrows; their normal slide/animation actions are not remapped. Test your clicker separately.

Privacy: this file includes everything it uses. There are no network requests, accounts, cloud uploads, microphones or speech recognition. Use Save backup as well as local autosave. Browser storage may be blocked or cleared.
