Try it without building

Open Source/reader.html, click Import, and choose Demo/Preview demo.script.json. You can also import a saved PowerPoint .pptx. Up/Down moves the line; Left/Right moves the local script slide. The browser alone cannot control running PowerPoint.

Use the native Mac companion

On macOS 13 or later, double-click Build Mac App.command in this folder. Install Apple's Command Line Tools when requested, then run the builder again. Open the generated Script Companion.app. Use a fresh folder when updating; the builder does not overwrite an existing app.

Start Presenter View with extended displays, not mirroring. In the reader's bottom setup drawer, link PowerPoint. Configure slide buttons separately and review the requested Automation/Accessibility permissions. Test the actual projector before presenting.

Your controls

Up/Down: lines. Left/Right: slides. T: timer. F: compact mode. P: preview. These mappings apply with the reader focused; PowerPoint-focused controls differ. Reset-all returns every slide to line 1 without clearing notes or timers.
