# Security and privacy

The project is a local presentation aid, not a security boundary. It uses macOS Automation to read PowerPoint and optional Accessibility access for deliberate keyboard delivery. Local state and backups are not encrypted by the app. Screen sharing, display mirroring, moving windows, or choosing the wrong window can expose your notes.

Do not publish credentials, personal paths, real speaker notes, proprietary decks or unsanitized diagnostics in an issue. Use a minimal, non-sensitive sample. Diagnostics are designed to omit note text but may include version information, window/deck identity or local paths; review the actual report before sharing.

If GitHub's private vulnerability reporting is enabled for this repository, use it for sensitive reports. Otherwise, open an issue with only a non-sensitive request to arrange private reporting; do not post technical details that expose private data. Private reporting and a response SLA are not guaranteed by this file.

No separate security-supported release line is currently maintained. Review updates and rehearse before replacing a working presentation setup. The builder never asks you to disable Gatekeeper/SIP or grant administrator access. Do not bypass an organisation's restrictions to use this tool.
